# Snake Game

Современная реализация классической игры "Змейка" на React с пиксельным дизайном, системой бонусов и глитч-эффектами.

**Автор:** Кутельвас Александр

## Установка

```bash
npm install
npm start
```

Откройте [http://localhost:3000](http://localhost:3000) для запуска игры.

## Особенности игры

- Классический геймплей "Змейки" с современными улучшениями
- Пиксельный дизайн с детализированной змейкой и яблоком
- Система бонусов с 5 различными типами
- Переключение темной/светлой темы
- Глитч-эффекты и анимации
- Функция паузы и контроль скорости
- Прогрессивное увеличение сложности

## Управление

- **WASD** или **Стрелки** - Движение змейки
- **ПРОБЕЛ** - Начать игру / Пауза
- **P** - Пауза / Продолжить
- **+/-** - Изменить скорость (50-300мс)
